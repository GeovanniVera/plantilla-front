# Internacionalización (`src/lib/i18n/`)

## Propósito

Configura i18next + react-i18next con dos idiomas (español e inglés). `main.tsx` la importa como side-effect (`import './lib/i18n/config'`), de modo que el idioma está disponible antes del primer render.

## Configuración (`config.ts`)

| Opción | Valor |
|---|---|
| `lng` | `localStorage.getItem('i18n_lang')` o `'es'` por defecto |
| `fallbackLng` | `'es'` |
| `interpolation.escapeValue` | `false` |
| Persistencia | en `languageChanged` se guarda el idioma en `localStorage` (`i18n_lang`) |

Si `localStorage` no está disponible (tests, modo privado), se cae a `'es'` sin lanzar errores.

## Errores (`errors.ts`)

`ERROR_MAP` asocia cada `ApiErrorCode` (de `src/lib/api/types/api-response.ts`) con una clave i18n bajo `errors.*`:

```ts
getErrorMessage(errorCode: ApiErrorCode): string  // traduce la clave con i18n.t
getErrorKey(errorCode: ApiErrorCode): string      // devuelve la clave sin traducir
```

| `ApiErrorCode` | Clave i18n |
|---|---|
| `NETWORK_ERROR` | `errors.network` |
| `TIMEOUT` | `errors.timeout` |
| `UNAUTHORIZED` | `errors.unauthorized` |
| `FORBIDDEN` | `errors.forbidden` |
| `ACCOUNT_SUSPENDED` | `errors.accountSuspended` |
| `NOT_FOUND` | `errors.notFound` |
| `CONFLICT` | `errors.emailAlreadyExists` |
| `RATE_LIMITED` | `errors.tooManyRequests` |
| `INTERNAL_ERROR` | `errors.server` |
| `VALIDATION_ERROR` | `errors.validation` |
| `UNKNOWN` | `errors.unknown` |

Este módulo es el que el API client usa para traducir los mensajes de error de red/timeout/status.

## Locales

- `src/lib/i18n/locales/es.json`
- `src/lib/i18n/locales/en.json`

### Claves disponibles

| Grupo | Contenido |
|---|---|
| `auth.*` | `login`, `register`, `forgotPassword`, `resetPassword`, `verifyEmail`, `verifyOTP` (títulos, subtítulos, placeholders, botones) |
| `errors.*` | mensajes de error (ver tabla de arriba) |
| `pages.*` | `forbidden`, `notFound`, `serverError`, `terms` |
| `common.*` | `loading`, `retry`, `cancel`, `save`, `delete`, `confirm`, `back`, `next`, `optional` |

Ejemplo de uso en componentes:

```tsx
import { useTranslation } from 'react-i18next';

const { t } = useTranslation();
t('auth.login.title');
```

## Deudas conocidas

- **`es.json` está en voseo rioplatense** ("Accedé", "tenés", "Registrate", "Creá"), no en español neutral. La documentación del proyecto se escribe en español neutro-profesional y NO debe replicar ese registro. Si se busca neutralizar la UI, es una tarea pendiente sobre `es.json` (afecta textos visibles, no claves).
